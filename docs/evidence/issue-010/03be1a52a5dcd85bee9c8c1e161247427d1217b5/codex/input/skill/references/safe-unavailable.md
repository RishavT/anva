# Safe unavailable behavior

Treat missing authentication, denied access, revoked credentials or sources,
unknown repositories, unsupported contract or packet schemas, read-only
proposal capability, and network failure as explicit unavailable states.

Do not fall back to another Anva interface, broaden retrieval, infer hidden
knowledge, or claim Anva alignment. Prepare and build may offer local-only work
after the user accepts limitations. Preflight may run local checks but remains
advisory and `UNVERIFIED`. Learn may return a draft marked `NOT_SUBMITTED` and
must create no external state.
