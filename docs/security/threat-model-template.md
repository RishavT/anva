# Threat model: System or change

## Assets

List protected data, credentials, evidence, and availability properties.

## Actors and trust boundaries

Describe users, services, third parties, and every boundary crossed.

## Data flows

Describe inputs, storage, processing, outputs, retention, and deletion.

## Threats and mitigations

For each threat, record likelihood, impact, current controls, residual risk, and owner.

## Verification

Link tests, reviews, monitoring, and incident procedures that prove the controls.
