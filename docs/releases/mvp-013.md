## Explicit limits

- Production deployments supply unique secrets, TLS, trusted proxies, backups,
  and monitoring. The release is not a managed-production claim.
- Decommissioning revokes access but is not verified legal erasure.
- Chromium is the browser target; other engines are unverified.
- Supported post-expiry session entry, external object-store recovery,
  persistent observability, and managed/commercial controls remain #37–#40.
- Canvas issue #49 retains its unchanged performance target and explicit
  post-MVP disposition.
- The open `anva-test#18` multi-stage harness defect is not represented as a
  completed private 31-review ceremony; the frozen product gate used
  deterministic 31-case breadth plus one independent representative review.

Current-main changes after `e89b06a` are not part of immutable v0.1.6. The next
patch is `v0.1.7` and requires an entirely new reviewed release ceremony.
