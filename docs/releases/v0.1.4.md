# Anva 0.1.4

Status: release candidate preparation. No `v0.1.4` tag, image, approval, or
GitHub Release exists until separately authorized protected-environment gates
succeed.

This fix-forward patch includes deterministic construction from #91, the
single-byte OCI lineage from #96, and the protected decision verification
binding from #101 in one immutable product source. The release workflow accepts
only `v0.1.4` and requires the full candidate commit. The tag, checkout, OCI
revision, artifacts, predicates, and published digest must all bind to that
exact commit.

Publication requires a fresh attested vulnerability proposal and an explicit
personal protected-environment decision by RishavT. The v0.1.0 vulnerability
exception is historical evidence only. Evidence and approvals from the aborted,
unpublished v0.1.1, v0.1.2, and v0.1.3 attempts cannot be replayed for v0.1.4.
The separate human operator acceptance drill is not approved by release
automation.

Rollback uses the verified immutable v0.1.0 digest only after confirming schema
compatibility, or restores a verified backup. Tags, assets, attestations, and
digests are never moved or overwritten.
