GitHub Release exists until separately authorized protected-environment gates
succeed.

and the least-privilege Skopeo auth-file identity fix from #106 in one immutable
product source. The release workflow accepts only `v0.1.5` and requires the
full candidate commit. The tag, checkout, OCI revision, artifacts, predicates,
and published digest must all bind to that exact commit.

Publication requires a fresh attested vulnerability proposal and an explicit
personal protected-environment decision by RishavT. The v0.1.0 vulnerability
exception is historical evidence only. Evidence and approvals from the aborted,
unpublished v0.1.1 through v0.1.4 attempts cannot be replayed for v0.1.5. The
separate human operator acceptance drill is not approved by release automation.

Rollback uses the verified immutable v0.1.0 digest only after confirming schema
compatibility, or restores a verified backup. Tags, assets, attestations, and
digests are never moved or overwritten.
