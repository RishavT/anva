# Support

Anva `v0.1.1` is an MVP patch release in preparation. Public GitHub issues are appropriate for reproducible
product defects and documentation problems that contain no sensitive data.

Security issues must follow `SECURITY.md`. Licensing and commercial support
enquiries should be sent to `rishav@aisoftwork.com`. Do not send credentials,
customer content, database dumps, or unredacted logs unless AI Soft Work first
provides an approved secure transfer method.

Public source availability does not create a service-level commitment. Support
terms for production deployments require a separate written agreement.
