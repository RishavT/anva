# Local evidence rules

Inspect only the repository and task the user placed in scope. Bind preflight
evidence to the exact diff and forty-character commit SHA. Report each check as
passed, failed, missing, skipped, or unavailable with its command and local
evidence.

Never equate local checks, an MCP response, or a proposal with independent
server assurance. Do not use `READY`, `PASSED ASSURANCE`, `SAFE_TO_DEPLOY`, or
similar final-approval language. Call the result a local advisory preflight.
